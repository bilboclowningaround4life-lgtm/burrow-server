    Public status card

    This Components V2 card is updated every five minutes. Save changes, then publish immediately when the bot and public-status channel are configured.

    Notification channels

    Set a Discord channel ID for any stream you want. Leave a field empty to turn that stream off. Changes take effect immediately.

    GitHub game updates

    Signed pushes become Components V2 commit cards. Client/SWF and game-asset pushes are marked as game updates.

    Discord security

    AutoMod deletes matching messages and posts an audit card without storing message text. Anti-raid sends an alert when the join limit is reached. Enable the Message Content and Server Members intents for this bot in the Discord Developer Portal, then reconnect it.

    Tickets and member notices

    Tickets open with `/ticket open` and remain visible to the opener and the configured staff role. Welcome and goodbye messages support `{user}` and `{server}`.

    Discord server moderation

    The consolidated bot also provides `/discord timeout`, `/discord untimeout`, `/discord kick`, `/discord ban`, `/discord unban`, and `/discord purge`. Give its Discord role the matching server permissions (Moderate Members, Kick Members, Ban Members, and Manage Messages) and keep that role above members it should moderate. Burrow staff permissions remain the first check.
